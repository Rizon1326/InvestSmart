# Market Analysis - Core Analysis Pipeline

This directory contains the core analysis pipeline components for market data processing and analysis.

## Components

- **scraping/**: Data collection from various sources (Foodpanda, Daraz, etc.)
- **forecasting/**: Predictive modeling using Prophet, SARIMAX, XGBoost, LightGBM
- **groq/**: Llama-3.1-8b-instant integration for advanced analysis
- **recommendation/**: Fit score engine for generating recommendations
- **finance/**: Simulation & ROI model calculations
