# Frontend - Visualization Layer

This directory contains the frontend components for the Market Analysis Platform.

## Structure

- **market-analysis/**: Core visualization components
  - **charts/**: ROI, sales forecast charts
  - **components/**: Recommendation & KPI cards
  - **utils/**: Data adapters

## Purpose

Provides an interactive visualization layer for market analysis data, including real-time charts, KPI dashboards, and recommendation interfaces.
